# 🌌 GravityFlip Unity

A fast-paced 2D casual game built in Unity. Features smooth gravity-manipulation mechanics, an interactive UI, and polished gameplay.

---

## ✨ Features
- **Gravity Inversion Mechanics:** Flip the player's gravity on click/tap to dodge obstacles on the ceiling and floor.
- **Dynamic Speed Progression:** The game gets progressively faster to test your reflexes.
- **Modern Minimalist UI:** Polish scoreboards, main menus, and settings configurations.
- **Particle Effects:** Micro-animations for crash events and gravity transitions.

## 🛠️ Tech Stack
- **Game Engine:** Unity (2D Project Configuration)
- **Programming Language:** C# (.NET Core Framework)
- **Physics Engine:** Unity 2D Physics (Rigidbodies and BoxColliders)

## 🚀 How to Run & Play
1. **Prerequisites:** Ensure you have **Unity Hub** and **Unity Editor (2021.3+)** installed.
2. **Clone the repository:**
   ```bash
   git clone https://github.com/saravana-GT/GravityFlip_Unity.git
   ```
3. **Open in Unity:**
   - Launch Unity Hub, click **Add**, and select the cloned project folder.
   - Wait for Unity to download packages and compile the scripts.
4. **Play:**
   - Open `Assets/Scenes/MainScene.unity` or `SampleScene.unity`.
   - Click the **Play** button at the top center of the editor.
   - **Controls:** Click the mouse button (or tap the screen on mobile) to invert gravity.
